Flashing Guide

Clean install required when switching from stock firmware or other custom ROMs.

01
Flash Core Partitions via Fastboot
Reboot to bootloader (adb reboot bootloader) and execute:
fastboot flash boot boot.img fastboot flash vendor_boot vendor_boot.img fastboot flash dtbo dtbo.img fastboot flash vbmeta --disable-verity --disable-verification vbmeta.img fastboot reboot recovery
02
Format Data in Recovery
In recovery: Select Factory Reset → Format Data/Factory Reset and confirm.
# In AOSP Recovery: # 1. Tap Factory Reset # 2. Tap Format data/factory reset # 3. Confirm format # 4. Return to main menu
03
Sideload ROM Package
Select Apply update → Apply from ADB and run on host:
adb sideload Project_Infinity-X-4.0-BETA-tank-*.zip # Once sideload completes (step 2/2): # Select "Reboot system now"
